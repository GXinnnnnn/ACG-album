# ACG-album

**把本地文件夹，变成值得翻看的卡片相册。**

ACG-album 是一款面向 Windows 的本地文件夹浏览与相册管理应用，专为 ACG「囤囤鼠」整理收藏的习惯做了优化。无论你收藏的是游戏 CG、动画截图、角色插画、设定集，还是普通照片，都可以保留熟悉的文件夹层级，用封面卡片和媒体瀑布流浏览。

批量导入收藏目录，检索对应的 **Bangumi 作品条目**，为相册匹配封面、简介与评分；再配上现代的玻璃质感界面、柔和配色与流畅动效，让硬盘里的收藏更容易找到，也更愿意打开。

当前版本 **0.6.0** · Windows x64 · Electron + 原生 HTML / CSS / JavaScript · MIT License

## 功能亮点

### 文件夹就是相册

- **卡片式浏览本地目录**：保留原有文件夹结构，用封面、标题、媒体数量和作品资料呈现收藏；支持逐层进入子目录。
- **批量导入，边扫边看**：导入收藏根目录后，子目录逐层成为相册。索引在后台分批建立，已载入的内容可以继续浏览，右下角显示扫描与资料匹配进度，并支持取消。
- **文件夹与媒体连续浏览**：统一浏览图片、GIF、动态 WebP 与视频；切换卡片尺寸、详情模式和紧凑瀑布流，保留滚动位置。
- **大图库增量维护**：重扫时复用未变化条目的索引与缓存，补齐新增或变动内容，清理已移走目录的失效记录。

### 为 ACG 收藏补齐作品资料

- **批量匹配 Bangumi 条目**：导入时可启用作品匹配，并选择动画、书籍 / 漫画、游戏、三次元等类别，根据文件夹名称查找对应作品。
- **封面、简介与评分**：先使用本地资料索引识别作品，再按确定的条目 ID 联网补齐当前详情与封面；离线时仍可浏览本地相册和随包资料。
- **中、日、英文名称检索**：结合原名、译名、别名和作品类型判断候选；名称存在歧义时保留人工选择，避免随意绑定同名作品或续作。
- **手动整理优先**：可手动检索、保存作品关联，选择本地封面并调整裁切。刷新或自动补齐资料时保留人工关联与手动封面。
- **独立本地资料检索**：从侧栏搜索作品、人物和角色，用作品类型或所属作品 ID 缩小范围；完整版还可展开离线摘要。

### 让收藏更好看，也更好找

- **现代界面与细腻动效**：玻璃质感、圆角卡片、柔和粉色强调与深浅主题；侧栏、弹窗和进度反馈保持统一风格，并适配减少动态效果设置。
- **搜索与收藏**：按名称检索，按名称、日期或大小排序；收藏常看内容，使用多层目录树定位相册。
- **时间线浏览**：全库或指定相册及其子目录可按月份、本地地点筛选，优先使用 EXIF 拍摄时间。
- **原图与媒体查看**：双击打开查看器，方向键切换、滚轮缩放、拖动平移；视频使用 Chromium 播放控件，不支持的编码可交给系统应用。
- **编辑副本**：裁剪、旋转、调色、缩放，查看 GIF / WebP 动画帧并导出新文件；编辑器拒绝覆盖原件。

## 开始使用

1. 安装所需的精简检索版或完整检索版，启动 ACG-album。
2. 点击侧栏「导入」，选择收藏目录。需要自动补齐作品资料时，开启 Bangumi 匹配并选择相应作品类型。
3. 等待目录索引建立，期间可浏览已经出现的相册。扫描进度与作品资料匹配是两个阶段，扫描完成后资料队列可能仍在继续。
4. 右键相册可修改相册类型、检索并保存作品关联，或手动选择和裁切封面。
5. 从侧栏进入「本地资料检索」查找作品、人物、角色；在偏好设置中切换主题和调整显示方式。

自动匹配采用保守策略，不能保证所有文件夹名称都准确识别。缩写、非官方译名、复杂备注或同名作品可通过手动关联修正。普通照片相册可以关闭作品匹配。

公开条目通常可匿名查询。部分条目需要在「偏好设置 → 作品简介」填写具有相应权限的 **Bangumi Access Token**；网页登录状态不会自动用于 API，是否可访问由 Bangumi 服务端与账号权限决定。应用不内置共享凭证。

## 精简与完整检索版

两版功能与名称匹配规则相同，区别主要是附带的离线资料体积。

| | 精简检索版 Lite | 完整检索版 Full |
| --- | --- | --- |
| 适用场景 | 日常名称检索、作品匹配 | 需要较完整离线简介与原始资料 |
| 名称、别名与直接关联检索 | 支持 | 支持，名称覆盖相同 |
| 离线长简介、infobox 与原始记录 | 精简 | 保留，部分字段供后续使用，未全部在界面展开 |
| 随包数据库 | 约 1.052 GB | 约 4.734 GB |
| 0.6.0 安装包 | 约 281.1 MB | 约 621.0 MB |
| 程序与索引解压占用 | 约 1.43 GB | 约 5.12 GB |

两版均收录 **695,909 部作品、103,653 个人物 / 团体、223,927 个角色、4,614,852 条展开的直接关联**，固定数据版本为 `2026-10-13.210353Z`。完整版不会额外提高名称匹配准确度；**两版都不内置封面图片**，在线封面与当前详情需要网络和相应访问权限。数据来源、字段与校验信息见 [本地检索数据说明](docs/LOCAL_SEARCH_DATA.md)。

选择一版安装即可。两版使用相同应用身份与用户数据目录，可运行另一版安装包覆盖切换；升级前建议备份应用数据。安装器支持选择安装目录，卸载默认保留应用数据。安装包尚未申请发行者代码签名，Windows 可能提示未知发布者。

## 数据与隐私

- **收藏留在原处**：浏览、索引、作品关联和封面调整不会移动、重命名或删除导入的原始文件；封面裁切只保存显示参数，移除分类只移除索引。
- **整理结果保存在本机**：默认资料目录为系统「文档」中的 `ACG-album`，保存索引、缩略图、设置、手动元数据和加密 Token。备份整个资料目录可保留整理结果。
- **兼容旧资料**：启动时依次检查 `文档/拾光相册/library.sqlite` 与 `文档/玖玖瑠相册/library.sqlite`，检测到旧资料时继续使用；两者同时存在时优先前者。
- **按需联网**：Bangumi 匹配会向相应服务发送作品检索词或条目 ID，并下载详情与封面。未开启匹配的导入可在本地进行，离线也能浏览已索引内容。
- **凭证在本机管理**：Windows 上的 Bangumi Token 使用 Electron `safeStorage` 加密保存，变更账号后隔离查询缓存。请勿将个人资料目录、Token 或图库提交到仓库。
- **副本导出**：编辑导出为新文件，转为 SDR sRGB，并移除 EXIF / GPS；不会修改原件。

检查更新由用户手动触发，可在应用内填写 GitHub `owner/repository` 或仓库地址查询稳定 Release。应用本身不自动下载或安装更新。

## 开发与构建

建议环境：**Windows x64、Node.js 24、pnpm 11**。主要依赖为 Electron 40.10.6、Sharp 0.34.5、exifr 7.1.3，索引使用 SQLite WAL 与 trigram FTS5。模块分工见 [项目结构](docs/PROJECT_LAYOUT.md)。

```powershell
pnpm install --frozen-lockfile --ignore-scripts
node node_modules/electron/install.js
pnpm start
```

运行测试与基础构建：

```powershell
pnpm test
pnpm run format:check
pnpm run package:dir
pnpm run package:installer
```

`package:installer` 是基础程序构建，不会自动下载离线资料库。与 Releases 一致命名的纯软件版使用 `pnpm run package:standard` 构建，随后可用 `pnpm run verify:standard` 隔离验证。精简 / 完整两版使用 `pnpm run package:search` 构建，随后可用 `pnpm run verify:search` 从安装包解压并隔离验证。双版构建脚本读取预处理的 Archive 数据及校验清单，运行前需根据 [本地检索数据说明](docs/LOCAL_SEARCH_DATA.md) 准备数据，并通过 `ACG_INDEX_SOURCE` 指定目录；源码仓库不包含大型数据库、安装包、个人图库或本地测试报告。

Electron 安装脚本在首次准备运行时下载所需运行时。若环境设置了 `ELECTRON_RUN_AS_NODE`，启动 GUI 前需移除。构建默认使用 `--publish never`；提交源码不会自动发布安装包。

### 验证与性能

自动化回归覆盖本地索引、匹配、导入、缓存和十万文件隔离用例。安装包验收从最终安装文件解压程序，在独立资料目录检查启动、明暗主题、窄窗口进度布局、导入与失效目录清理；Lite / Full 另核对真实资料检索、类型限制与候选一致性，Standard 核对未安装本地索引时的提示。验收不覆盖正式安装或私人相册。

十万文件回归测得首次索引约 26 秒、导入期间读取请求 P95 约 26 毫秒，移走整棵子目录后的失效清理约 67 秒。该用例使用空 JPEG 占位文件测量文件系统索引与数据库响应，**不代表真实图片解码或 Bangumi 联网同步速度**。完整诊断报告保存在维护者本地归档，不随源码提交。

GUI 与性能脚本应逐个运行。部分维护脚本包含维护者本机路径或系统集成操作，使用前请检查目标；`check-installer.cjs` 会进行临时安装与卸载，不能在已有同名正式安装的机器上直接运行。

### 格式与使用边界

- 常见 JPEG、PNG、WebP、GIF、BMP、TIFF、AVIF 可索引；HEIC / HEIF 解码依赖具体编码和 Sharp 构建，视频播放取决于 Chromium 支持的容器与编码。
- APNG 目前仅可靠支持静态提取，不提供可靠的 APNG 多帧编辑导出。
- 高位深与宽色域会显示相关提示；缩略图和编辑副本为 SDR，尚未验证 HDR 显示器的端到端输出。
- 虚拟网格与缓存按需加载；实际滚动、导入和解码速度受磁盘、媒体格式、缓存与窗口环境影响，不承诺任意规模图库或固定 4K 60fps。
- 联网请求按至少约 1.05 秒间隔串行，并处理限流与退避；大批量不同作品的资料同步可能需要较长时间。
