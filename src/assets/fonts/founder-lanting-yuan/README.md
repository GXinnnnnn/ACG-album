# 系统字体与历史来源记录

本目录仅保留历史来源元数据，不随源码、安装器或运行时载荷提供任何专有字体二进制。界面只能通过 `local()` 调用用户操作系统已经安装的字体；不读取本目录或旧应用资源中的字体副本，也不联网下载专有字体。

`PROVENANCE.json` 保留旧本机副本的五种原始文件名、大小、SHA-256 与版权，用于精确识别历史应用所有的副本并保存私有恢复备份。它不是字体授权，不应据此获取或重新分发字体。未知文件不按名称推断所有权。

方正字库的原版权为 `Copyright(c) Beijing Founder Electronics Co.,Ltd.2014`，不适用项目 MIT。OS/2 `fsType=8` 仅表示 editable embedding，不是通用再分发许可。用户安装字体的使用范围仍遵循其自行取得的授权。

应用离线后备字体及完整 SIL OFL 1.1 许可在相邻的 `source-han-sans/` 目录中；原始字体与许可均保持上游原样。
