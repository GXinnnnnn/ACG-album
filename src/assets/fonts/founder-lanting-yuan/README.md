# 方正兰亭圆：本地版本字体副本

本目录按用户的明确请求，从这台电脑现有的五个方正兰亭圆 GBK 字体文件逐字节复制，用于当前未发布的本地应用。没有下载、安装、子集化、修改字体，也没有移除字体内的版权或嵌入信息。

| 文件 | 原字体家族 | 应用中的字重角色 |
| --- | --- | --- |
| regular.ttf | 方正兰亭圆_GBK | 400 正文 |
| medium.ttf | 方正兰亭圆_GBK_准 | 500 中等 |
| semibold.ttf | 方正兰亭圆_GBK_中 | 600 半粗 |
| bold.ttf | 方正兰亭圆_GBK_中粗 | 700–800 粗体 |
| heavy.ttf | 方正兰亭圆_GBK_特 | 900 特粗 |

原文件的 OS/2 weight class 均为 400，应用通过 CSS 的不同字形来源明确映射以上字重，不依赖系统伪加粗。文件大小、SHA-256、中文家族名及原版权记录见 `PROVENANCE.json`。字体以离线应用资源加载；用户显式选择的其他本地字体仍优先。
