# 1.1.1

本轮为 1.1.0 的界面、导入反馈与更新体验修订。版本采用三段式编号：小更新递增末位，例如 1.1.1；较大的功能改动递增中间位并将末位归零，例如 1.2.0。

## 界面与导入反馈

- 浅色界面的次要文字加深，字重略增；深色界面相应提高文字亮度，保持说明、提示与状态的可读性。
- 设置等弹窗的圆角磨砂中心四边等距，短内容页面底部也延伸至相同边距，四周液态玻璃连续过渡到中心。本次替换修订在本地试用基础上每边收小 2px，设置页四边留白为 18px；滚动和切换面板后保持一致。查看器继续保留原有淡磨砂材质。
- 去除设置等内部滚动弹窗外壳重复预留的滚动槽，修复右侧额外半透明细条。弹窗及内部列表的滚动条跟随浅深主题，正常内部滚动保留。
- 右下导入检索面板使用固定尺寸和固定行位。标题、已处理／待处理计数、当前作品或目录名、提示各占独立位置；长名字单行省略，状态切换不改变字体和面板尺寸。
- 作品简介检索使用「已处理 ÷（已处理 + 待处理）」显示已知工作量，发现阶段也保留真实计数；继续发现待检索项时总量可能增加，进度会据实调整。纯文件扫描缺少待处理总数时保留扫描状态，不使用预测总数。
- 全新且尚未配置的资料库首次进入简介／元数据设置，滚动到 token 输入处。已有 token 或已导入目录的资料库跳过自动引导；关闭后不会在每次启动时再次弹出。

## 更新与资料保留

更新界面从 GitHub 的最新发布同步版本、说明和与当前安装版型对应的资源。应用内更新使用完整安装载荷，下载完成后先核对长度和 SHA-256，再交给安装器；不通过移动个人资料完成更新。Token、已索引目录与个人设置继续存放在原资料目录。仅正式 Windows x64 运行环境支持应用内安装；下载和安装均由用户点击。安装前检查路径及已有安装记录，预检失败时应用保持运行并提示手动安装；固定目录部署也可更新。安装载荷已解包并在隔离资料中启动检查，真实 NSIS 覆盖安装、UAC 和重启全链路尚未在用户环境端到端实测。

Standard、Lite、Full 公开安装器均排除专有方正 TTF；本机固定目录保留现有本地字形。两启动入口和固定资料目录继续使用既有位置。

## 发布约定

用户指定本轮沿用当前最新发布记录，将标题、版本、说明与附件替换为 1.1.1；标题不加中文后缀。发布前必须先同步并保留用户在 GitHub 修改的 README 和其他标题，验证三版附件与本地交付成品相符后再替换旧资源。网络不可用时不将本地暂存误记为已发布。
