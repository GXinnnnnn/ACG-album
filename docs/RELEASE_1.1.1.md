# 1.1.1

2026-10-30 全套替换修订，包含本轮外观控制和此前本地弹窗、检索、导入优化。沿用现有 `v1.1.1` 标签与发布记录，重新提供源码、Standard／Lite／Full 完整安装包、说明和校验附件。

## 外观与可读性

- 新增全局字体阴影开关，默认关闭；开启后只使用淡阴影，无发光和文字描边。液态玻璃透明度与磨砂玻璃透明度独立调节，范围 0–90%，默认 18%／8%；数值越小越不透明，不改变文字和图标本身的不透明度。
- 全局卡片圆角支持 0–36px，默认 16px，0px 为方角；头像与功能按钮保留原形。卡片尺寸支持 120–360px 连续调节，默认 222px，保留 158／186／222px 三档，网格从左上方自适应排布，窄窗口不横向溢出。
- 滑杆支持鼠标、键盘、即时预览、合并保存与重启保留；右侧均提供恢复默认与悬停说明。封面缩放／位置和图片调色也增加逐项恢复，播放定位条保留原用途。
- 中置窗口默认更不透明，滚动条更细偏粉；悬浮文字及图标颜色加深。淡灰占位提示、强调和危险操作等语义保留；图标路径、形状、尺寸与线宽保持。

## 弹窗与导入检索

- 弹窗改用整面均匀磨砂，取消中央独立 SVG 遮罩及磨砂／液态过渡带；保留外轮廓轻微玻璃感。查看器的独立淡磨砂框和清晰中央媒体保持。
- 修复属性、调整封面位置、详细信息、设置、关于、更新与右键浮层右侧多出的半透明区域；滚动内容放在内部，玻璃外壳四边覆盖完整。焦点环绘于控件边界内，避免关联输入框左侧被滚动区域裁切。
- 自动与手动检索使用相同的有限分页与缓存，详情核验推翻首个同名结果后，仍查找后页真实匹配及歧义候选。保留最多 3 个搜索请求、6 个详情核验与既有置信门槛、类型及双语冲突保护。历史已终结的漏配项可通过现有重新检索入口重试。
- 导入心跳和匹配批次按实际变化更新目录树、主题和设置，保留节点、焦点与滚动位置；相同画布尺寸不重置位图。滑杆读数更新不再重建背景纹理，连续输入合并保存及重绘。
- 右下导入检索面板固定尺寸、字体和行位；进度按已处理与待处理的真实总数计算。首次无配置资料库自动打开作品简介并定位 Token，已有资料库跳过引导。

## 更新与安装

Standard 不附带离线索引；Lite／Full 使用同一名称检索覆盖，Full 额外保留完整资料。三版使用同一应用身份，只安装其中一个即可。覆盖切换继续使用原资料，不移动个人图库。公开源码与安装器不附带方正专有 TTF，使用本机已安装字形或系统回退；本机固定交付保留既有字形和两启动入口。

**已安装上一轮同号 1.1.1 的用户请手动下载本次安装包，退出程序后覆盖安装。** 常规版本检查只提示严格更高版本，本次同号替换不会触发升级提示。下载后可按 `SHA256SUMS.txt` 核对文件；精确附件大小、摘要及实际验收范围以本次 `VALIDATION_REPORT.json` 为准。

应用内更新按当前 Standard／Lite／Full 版型获取完整安装包，核对长度与 SHA-256 后由用户点击安装；安装前预检路径及资料，随包索引先备份，成功验证后清理、失败恢复。Token、已索引目录和设置保留原位。安装载荷使用隔离资料解包并启动验收；真实 NSIS 覆盖安装、UAC 和重启全链路尚未在用户环境端到端实测。

## 版本规则

版本号保持 1.1.1，发布标题不加中文后缀。后续小更新递增末位（如 1.1.2），较大改动递增中间位并将末位归零（如 1.2.0）。本次保留 README 的五张用户截图，替换现有发布全部八项附件，并保留原发布记录。
