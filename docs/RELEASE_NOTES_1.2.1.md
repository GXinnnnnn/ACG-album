# ACG-album 1.2.1

2026-11-06 同版本修订：将此前本机标作 1.2.2 的开发成果并入现有 1.2.1，沿用 [v1.2.1 发布页](https://github.com/GXinnnnnn/ACG-album/releases/tag/v1.2.1)、标签及三版原安装包名称，替换现有附件，不新增公开 v1.2.2。Standard、Lite、Full 共用应用功能与个人资料格式，三个版本选择一种安装即可。

**已安装 1.2.1 的用户不会收到更高版本提示，需手动下载修订后的同版完整安装包并覆盖安装，才能获取本次变化。** 安装前备份个人资料，按本次替换发布的新大小和 SHA-256 校验文件；下载与备份步骤见 [安装说明](INSTALLATION.md)。

## 2026-11-06 同版本修订

### 相册返回保留真实卡片

父相册进入子相册再返回时，先恢复原卡片按钮、图片元素、已加载状态和滚动位置，再后台按项目身份与数据代次（epoch）校验刷新。缓存最多保留两个非活动视图，共享最多 180 张真实卡片，每个视图最多七页数据与高度摘要，不保留全库 DOM。超出预算、清空缓存或数据确实变化时允许冷加载。

尺寸、密度或 DPR 变化时重新测量；需要新缩略图档位时才更新图片地址，队列优先级改变不会重载同一封面。旧数据回包不能覆盖已切换的当前视图。

### 按目录层级默认排序，保留显式记忆

导入根目录所列一级相册默认名称升序（`name/asc`）；进入一级相册及其后代目录默认内容日期倒序（`contentDate/desc`），以导入根身份判断层级。用户明确选过的排序和方向按页面保存、优先于默认值，即使首次点击当前默认值也会记住。

日期准备未完成时先按名称升序显示，完成后对需要日期排序的活动页面按项目身份重排，保留未变化卡片。文件夹优先；文件夹使用创建时间并回退修改时间，照片优先已有 EXIF 拍摄时间，其他媒体使用有效文件系统时间。

### 日期准备按真实阶段显示进度

日期缓存使用 `migrateAsync`，默认每批回填 512 条、批量上限 4096 条，分批事务提交后让出执行，并保存续作游标。中断或失败不标记为就绪，既有触发器继续维护新增或变动记录。右下角区分读取状态、实际已提交回填数量、两个索引的建立阶段及失败状态。

SQLite 的 `COUNT` 和单次 `CREATE INDEX` 仍为同步原生调用；批次及两次建索引之间让出执行，不代表整个准备过程完全无阻塞。回填比例不代表全部工作完成比例，建索引阶段显示不定进度。

### 本体与资源分开更新

本体更新使用明确的运行时 ZIP 和清单；发布身份、平台、资源版型、数据版本、读取兼容性、大小与 SHA-256 通过校验后，才可保留原随包索引，仅替换本体。普通 Standard 安装器不能当作保留 Full 资源的本体包。资源变化或切换版型仍需完整安装包；缺少可信清单时提供 [GitHub 手动下载入口](https://github.com/GXinnnnnn/ACG-album/releases/tag/v1.2.1)。

自动安装另须可信的当前运行时所有权清单，目标安装器也须生成对应的新清单，安装与回滚逐文件核对 SHA-256。缺少清单、发现未知文件或校验不符时停止自动安装；旧安装缺少新协议清单时需手动完整覆盖，不能仅凭版本号宣称可自动更新。失败恢复原程序与资源并保留恢复证据。下载弹窗沿用现有外观，显示实际字节进度、失败原因和可点击的 GitHub 链接。

版型按实际随包索引识别；仅确认索引目录不存在才判为 Standard。清单损坏、未知协议或路径不可信时显示未知版型，停止默认下载并要求明确选择。个人资料、Token、收藏、人工关联、原图库路径及 ID、原随包索引与本机五份私有字体继续保护；专有 TTF 不进入公开本体或安装包，本机已有字形由受控外置层保留。

### 保留外观，Everything 仅作评估

原有液态／磨砂玻璃、动效与个人外观选择继续保留。本轮只评估 Everything SDK / IPC，没有集成 FFI、SDK 或常驻搜索服务；目录分页与日期语义继续使用现有 SQLite 和文件系统数据。

以下保留 2026-11-03 的原 1.2.1 功能记录；新修订的最终验证以文末验收状态为准。

## 首次中卡片与尺寸记忆

- 没有明确保存过尺寸的新资料库，从当前窗口的「中」档开始；最大化或改变窗口宽度后，在尚未手动选择时继续跟随中档。
- 点击小、中、大档位、拖动尺寸滑杆或使用 Ctrl＋滚轮，都按明确选择保存实际数值。即使点击的中档与当前数值相同，也会记住选择；重启后恢复最后保存的值。
- 已有明确数值的资料库继续使用原尺寸。手动选择、保存和后台设置摘要交错返回时，以本次手动选择为准。

## 连续目录树与索引隔离

后台索引的进度通知曾反复清掉展开目录的分页缓存，使正在显示的行短暂退回占位；停在底部时，临时回退到另一种目录总数还会改变滚动高度。本次在校验期间保留已显示的可见列表、总高度与滚动位置，待结果可用后再更新。

目录树继续使用有界的可见行和分页缓存，只列出文件夹。真实新增、删除、改名和根目录移除仍会刷新；较早请求不会覆盖新的滚轮位置、焦点或关闭操作。索引发现新内容仍需要实际扫描时间。

## 汇入此前本机修订

- 卡片画布左对齐，保留连续尺寸调节与随屏宽变化的三档预设；数量与评分底栏可完整显示五位数数量和最高评分。
- 左侧目录树连续滚动，底边随窗口高度调整；保留展开状态、焦点与深层目录定位。
- 日期排序中文件夹优先，文件夹以创建时间为主，照片优先使用有效拍摄时间，其他文件使用有效文件系统时间；创建日期、修改日期仍可独立排序。不同页面和目录分别记忆排序及方向。Windows 的文件类型处理程序可能提供额外日期信息，本应用不保证复现每一种系统处理程序。
- 增补已核验的人工名称关系，保留既有关系、歧义保护与用户人工整理结果。
- 保留资源读取与重命名之间的完整请求边界、外部目录改名刷新与目录焦点守卫，以及既有导入续作、取消、真实重命名和深层刷新行为。

## 安装、资料与字体

退出相册后使用所选版型的完整 1.2.1 安装包覆盖原程序目录。保留原资料目录、启动器的数据路径参数、原图库与缓存设置；升级前备份完整个人资料。Lite 和 Full 沿用同一份离线资料快照，名称覆盖相同；Full 额外保留长简介和原始资料，所有版本均不包含封面图片。详见 [本地检索数据](LOCAL_SEARCH_DATA.md)。

公开源码和安装器不附带五份方正专有 TTF；程序使用本机可用字形或系统回退。本机维护交付保留已有字形和个人选择，不代表公开再分发字体授权。
