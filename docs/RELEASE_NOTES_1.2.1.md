# ACG-album 1.2.1

本次修复首次卡片大小和左侧目录树闪烁，并把此前本机布局、日期排序与名称学习修订纳入正式版本。Standard、Lite、Full 共用应用功能与个人资料格式；三个版本选择一种安装即可。下载与备份步骤见 [安装说明](INSTALLATION.md)。

## 首次中卡片与尺寸记忆

- 没有明确保存过尺寸的新资料库，从当前窗口的「中」档开始；最大化或改变窗口宽度后，在尚未手动选择时继续跟随中档。
- 点击小、中、大档位、拖动尺寸滑杆或使用 Ctrl＋滚轮，都按明确选择保存实际数值。即使点击的中档与当前数值相同，也会记住选择；重启后恢复最后保存的值。
- 已有明确数值的资料库继续使用原尺寸。手动选择、保存和后台设置摘要交错返回时，以本次手动选择为准。

## 连续目录树与索引隔离

后台索引的进度通知曾反复清掉展开目录的分页缓存，使正在显示的行短暂退回占位；停在底部时，临时回退到另一种目录总数还会改变滚动高度。本次在校验期间保留已显示的可见列表、总高度与滚动位置，待结果可用后再更新。

目录树继续使用有界的可见行和分页缓存，只列出文件夹。真实新增、删除、改名和根目录移除仍会刷新；较早请求不会覆盖新的滚轮位置、焦点或关闭操作。索引发现新内容仍需要实际扫描时间。

## 汇入此前本机修订

- 卡片画布左对齐，保留连续尺寸调节与随屏宽变化的三档预设；数量与评分底栏可完整显示五位数数量和最高评分。
- 左侧目录树连续滚动，底边随窗口高度调整；保留展开状态、焦点与深层目录定位。
- 日期排序中文件夹优先，文件夹以创建时间为主，照片优先使用有效拍摄时间，其他文件使用有效文件系统时间；创建日期、修改日期仍可独立排序。不同页面和目录分别记忆排序及方向。Windows 的文件类型处理程序可能提供额外日期信息，本应用不保证复现每一种系统处理程序。
- 增补已核验的人工名称关系，保留既有关系、歧义保护与用户人工整理结果。
- 保留资源读取与重命名之间的完整请求边界、外部目录改名刷新与目录焦点守卫，以及既有导入续作、取消、真实重命名和深层刷新行为。

## 安装、资料与字体

退出相册后使用所选版型的完整 1.2.1 安装包覆盖原程序目录。保留原资料目录、启动器的数据路径参数、原图库与缓存设置；升级前备份完整个人资料。Lite 和 Full 沿用同一份离线资料快照，名称覆盖相同；Full 额外保留长简介和原始资料，所有版本均不包含封面图片。详见 [本地检索数据](LOCAL_SEARCH_DATA.md)。

公开源码和安装器不附带五份方正专有 TTF；程序使用本机可用字形或系统回退。本机维护交付保留已有字形和个人选择，不代表公开再分发字体授权。

## 验收范围

本轮验证包括完整 Node 回归与格式检查、隔离资料下的真实窗口与重启、索引期间目录树滚动和停底、Standard / Lite / Full 最终安装载荷解包及隔离启动、本机完整 Full 的真实检索与字体加载。实际通过数量、产物大小和 SHA-256 由该 Release 随附的 `VALIDATION_REPORT.md` 与 `SHA256SUMS.txt` 记录，不能用历史验收代替。

真实用户环境中的 NSIS 覆盖安装、UAC、系统重启全链路没有端到端实测保证；也不承诺私人图库的固定启动耗时。十万文件用例以空 JPEG 占位测试文件系统索引和数据库响应，不代表真实图像解码或联网同步速度。
