## 已有相册先显示，后台继续任务

- 轻量启动先读取已保存的根目录、设置和后台任务状态，展示真实的已导入内容。统计与本地检索索引状态延后加载，未缓存的内容仍需实际索引。
- 在页面内容出现后启动后台维护与任务恢复。界面区分读取中、排队、运行、暂停、受阻与维护错误，未知待处理数量不伪装为零。
- 未完成扫描保存任务和目录检查点；正常退出或正常关机后，下次启动继续。在线资料补全保留待续任务。
- 用户明确点击「取消」会终止该批次，不在下次启动自动重开；已经建立的索引与整理结果继续保留。恢复磁盘、权限或凭证后可按实际状态重试，维护错误也提供恢复入口。
- 强制结束、断电、损坏存储和全部文件系统组合不作无损续作保证。已经迁移的普通重启与首次旧库维护是不同场景，不能把某次运行耗时推广为所有资料库的启动速度。

## 真实文件与目录重命名

- 相册、图片和视频右键增加「重命名…」，显示原名称和实际路径。媒体扩展名固定保留，Enter 提交，Esc 关闭。
- 操作修改磁盘上的真实名称，并同步条目身份、子目录路径、作品与角色关联、收藏、人工资料、手动封面、裁切及缓存记录。导航中的当前目录、已展开目录和历史位置按新路径恢复，搜索与排序条件保持。
- 名称非法、同名目标、权限、文件占用和任务冲突会显示具体错误；同一提交不会重复发起，失败后可修改重试，不覆盖同名目标。
- 目录结构刷新在改名期间暂缓，任务与进度事件继续显示。异常恢复提示与真实路径用于协助核对；如发生需要人工处理的恢复状态，不应反复移动或删除相关文件。
- 应用内改名与外部工具搬动文件是不同操作。外部改动后应刷新核对，不承诺自动找回所有关联；超长路径与所有磁盘环境尚未全面验收。

## 刷新、手动关联与导入反馈

- 卡片尺寸右侧增加唯一工具栏刷新按钮；查看设置中的刷新入口与页面右键入口共用实际增量刷新。普通浏览时支持 F5 / Ctrl＋R，编辑、弹窗与查看器内保留原交互。
- 首页刷新逐个检查已导入根目录，单个目录失败会报告原因并继续其他目录；未变化的卡片、图片与缓存尽量复用，避免全页清空后重排。
- 手动关联先保存所选条目与基础资料、更新当前卡片，封面和详情后台补全。提示明确区分保存与补齐完成，不把单项操作升级为全库批量进度；真实既存导入仍可见。
- 候选的「100% 相关」解释为名称相关程度，用户仍须明确选择和保存，同名与歧义检查继续保留。
- 导入选择、扫描、在线补齐及取消收尾共用忙状态，添加入口保持稳定禁用反馈；取消请求采用单飞处理，等实际任务结束再释放。
- 小、中、大卡片档位随窗口适配，新资料库从中档起步，保留已保存的显式尺寸与外观。连续瀑布流跨页计算，长图卡片高度上限继续保留；增量刷新尽量保持当前浏览锚点。

## 保留的日常功能

保留 Standard / Lite / Full 三版、离线名称检索、Bangumi 作品与角色资料、手动封面及裁切、自然文件名排序、收藏、时间线、原图与视频查看、兼容预览，以及另存副本的图片和动画编辑。整面磨砂弹窗、明暗主题、字体与阴影选择、液态和磨砂透明度、卡片圆角、连续尺寸、动效强度和首页文案编辑继续保留。

README 的五张既有实际截图继续保留，用于展示日常界面。本轮重命名、恢复、首次引导及外观操作使用实际 Electron 窗口验收，报告与截图单独归档；公开说明不以示意图代替操作证据。

## 三版安装与资料保护

| 版型     | 随附内容                                                   |
| -------- | ---------------------------------------------------------- |
| Standard | 软件本体，不含离线 Bangumi 索引，可联网匹配                |
| Lite     | 软件本体与精简名称、别名、类型、日期及直接关联索引         |
| Full     | 软件本体与完整离线资料，额外保留长简介、infobox 与原始记录 |

三版共用功能与个人资料格式，只安装一种即可，退出程序后可覆盖切换。Lite 与 Full 名称覆盖和匹配规则相同，所有版本都不内置封面图片。快照不是网站实时资料，精确随包数据库和附件大小以最终 Release 为准。

升级前正常退出并备份完整实际资料目录，保留原启动器的资料路径参数；原图和另存缓存分别备份。浏览、索引、作品关联、封面显示调整不会改写原件；本轮新增的明确「重命名」会修改磁盘名称。安装器、更新和缓存清理不能替代个人备份。

公开源码与安装器继续排除方正专有 TTF，使用本机可用字形或系统回退；本机交付保留已有本地字形和个人选择，不改变公开字体授权边界。Token 在本机加密管理，不在仓库、截图与报告中公开个人凭证或图库路径。

## 验证与发布状态

最终源码完整回归 **960/960** 通过，无失败、取消或跳过项；真实源码窗口完成 **7 组、61 项**检查，覆盖正常关闭续作、明确取消不续作、缓存首屏、真实改名与冲突纠正、深层刷新、导入忙态、首次引导及外观。十万文件占位用例首次导入约 40.7 秒，期间 RPC 的 P95 为 56.4 毫秒；这些数据衡量索引与数据库响应，不代表真实图片解码或联网同步速度。三版成品的实际 NSIS 解包、随包索引及字体、完整程序界面验收与 SHA-256 单独记录在 Release 的 `VALIDATION_REPORT.md`，不以源码通过替代成品验收。

安装包验收使用实际 NSIS 提取载荷与隔离资料，不涵盖真实 UAC、覆盖安装及系统重启的端到端操作。启动测量使用个人数据库的隔离副本，关闭自动任务、网络和图片请求，并限制原件元数据访问；单次结果不代表用户私人环境中十几秒等待已被完整复现，也不宣称固定加速比例。历史报告仅对应其原版本与载荷；本版发布及远端附件的一致性以实际回读记录为准。
