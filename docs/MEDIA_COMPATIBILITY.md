# 本地版媒体兼容与浏览

本文对应正式 1.1.0 的媒体兼容实现。维护者本机继续使用固定的“启动相册”入口和“当前版本”目录。

## 图片查看

查看器先让 Chromium 打开原文件；无法直接显示时，应用读取实际文件签名，在缓存目录生成兼容 WebP，再显示该副本。原图和原始素材路径保持不变。缓存按文件路径、文件大小、修改时间及预览参数区分；修改生成素材后会重新预览。错误提示显示具体读取或解码原因，可继续用系统应用打开。

- JPEG、PNG、WebP、GIF、AVIF：优先直接显示；兼容预览处理常见方向标记、CMYK JPEG 和透明通道。扩展名错误时按实际内容设置图片 MIME。
- TIFF：使用兼容预览，取首个图像页；支持常见方向标记。多页文档的逐页浏览不在本次范围。
- BMP：覆盖常见 1/4/8 位调色板、16/24/32 位、上下方向、RGB 位域、RLE4/RLE8 和 OS/2 core 头；损坏数据或不支持的变体会给出原因。
- ICO：选择最大有效图像，支持常见内嵌 PNG、DIB 和透明掩码。
- HEIC / HEIF：随附独立的离线 libheif / libde265 WASM 解码器，读取主图后生成预览，不依赖系统安装 HEVC 扩展或在线服务。AVIF 仍使用 Sharp 自身的 AV1 支持。不同 HEVC profile、HDR、深度图、连拍和多图辅助内容不保证全部兼容。
- GIF、APNG、动画 WebP：原生显示成功时保留原动画；转成兼容副本时为静帧。浏览和编辑能力不同；多帧编辑导出仍受原有格式限制。

解码任务有资源上限。兼容预览一般最多读取 256 MiB，普通格式最多 8000 万输入像素，BMP 和 HEIF 最多 4000 万像素；HEIF 输入另限 64 MiB。JPEG 可在缩小解码路径下接受更大输入，但仍有限额。输出最多 2400 万像素、单边最多 8192 像素，不放大原图。超限会明确提示，不能据此承诺任意大图或所有格式变体都能解码。编辑副本的资源预算独立，能查看不代表一定能编辑。

HEIC 解码按需启动单独工作线程，限制队列和执行时间，超时终止线程；后续请求可重新启动。对应源码、完整许可、构建入口和可替换方法位于开发目录 `src/vendor/libheif`，打包后为 `resources/codecs/libheif`，详见 [第三方声明](THIRD_PARTY_NOTICES.md)。该目录不附带审核用测试照片。

## 视频打开

视频优先尝试 Chromium 自带的播放器。当前条目遇到无法解码、无法读取或约 10 秒仍未加载时，自动调用系统默认播放器，单次浏览只自动交接一次；切换条目、关闭查看器会取消旧条目的回调和计时器。系统未设置关联程序、文件丢失或系统打开失败时，界面显示系统返回的错误，并保留手动打开入口。自动交接不代表系统播放器一定支持该视频，也不安装额外视频编解码器。

## 全窗滚动与玻璃文字

主内容的滚动区域延伸到窗口上沿和底边；初始内容仍让出悬浮工具栏的位置，滚动时内容可以从其下方经过。末尾内容可滚动到真实底边。悬浮组件下方有已解码且可见的图片时，文字启用细描边与微弱光晕：浅色主题的深字使用浅色描边，暗色主题的浅字使用深色描边。图片离开后自动恢复普通文字，不为此新增持续空转动画。
