# 本地弹窗与导入检索管线修订

2026-10-30，在 1.1.1 上完成本地试用修订，现与外观控制一同纳入现有 `v1.1.1` 的全套发布替换：更新源码、三版公开安装器、发布描述及本机完整 Full 程序。实际资源摘要及发布完成状态以本轮验收与远端回读记录为准。

- 按最新试用反馈，全部非查看器弹窗改为与左侧边栏相同的整块均匀磨砂材质，共用背景叠层、主题透明度、真实 DOM 模糊与 WebGL 光学层。取消中央独立 SVG 遮罩、按文字计算的磨砂边界与中央／外围混合分支，避免额外过渡带；仍保留外轮廓的轻微液态玻璃感。此前 14px／10px 方案仅为中间试用，不进入本次最终本地程序；查看器独立淡磨砂框不变。
- 全部玻璃弹窗外壳取消没有溢出时预留的空滚动条槽。属性、调整封面位置、详细信息和“关于／检查更新”使用内部内容滚动，外层玻璃不再因真实滚动条丢失右侧画布宽度；内部面板保留稳定槽。右键菜单和选择浮层采用透明轨道和可见滑块，保留滚动与系统高对比度支持。
- 焦点环统一绘于控件边界内，防止关联输入框等在滚动裁切处丢失左侧边框。顶部搜索只在外层显示一圈焦点；媒体编辑器、查看器的独立高优先级规则同步修正。
- 提示占位文字使用独立颜色：浅色 `#726f79`，深色 `#9893a0`；帮助正文、实际输入值和字体设置保持原有语义。
- 自动与手动检索统一有限分页和召回缓存。搜索页同名仍须接受详情核验，不能提前阻断后页真实匹配或歧义候选；仍保持最多 3 个搜索请求、6 个详情核验，以及既有置信门槛、类型校验和双语冲突保护。HTTP 权限错误保留待处理任务，Token 更新后可以恢复；有效离线命中仍优先使用本地身份。
- 进度心跳仅在根目录、修订号或活动边界变化时刷新库摘要。自动匹配按批更新，不再使目录树结构缓存失效；相同可见树状态保留节点、展开页、焦点和滚动位置，树节点事件读取最新元数据。真实目录结构变化仍刷新并保留当前选择。
- 重复设置快照不重写相同主题、根样式、头像和动效属性。玻璃场景保持相同尺寸时不重置 canvas 位图；浮层替换自身子节点后可重新挂回原有玻璃画布，避免丢失光学层。

历史已经被旧逻辑终结的未匹配项不会通过本轮直接改写个人资料。需要重新尝试时，使用现有目录同步／重新检索入口，让它们进入修复后的召回管线。

验收采用隔离生成资料与图片，不操作个人相册，也不请求公开候选检索服务；进度／匹配批次的渲染稳定性使用明确标注的生产事件边界注入，与真实导入和结构更新分开记录。实际验收、构建和部署记录保存在 `C:\ACG\资料归档\popup-pipeline-20261030`。
