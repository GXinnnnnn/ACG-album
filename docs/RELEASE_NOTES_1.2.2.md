# 历史本机开发记录：1.2.2

本文保留 2026-11-06 本机开发阶段「相册返回缓存、渐进日期排序与本体更新」的说明。**这些功能最终并入 1.2.1 的 2026-11-06 同版本修订**，沿用现有 v1.2.1 标签、发布记录与三版原安装包名称替换附件，没有公开 v1.2.2 发布。当前功能与正式验收状态以 [1.2.1 说明](RELEASE_NOTES_1.2.1.md) 为准。

同号客户端不会收到更高版本提示，需从 [v1.2.1 发布页](https://github.com/GXinnnnnn/ACG-album/releases/tag/v1.2.1) 手动下载修订后的完整安装包覆盖获取。以下内容是开发记录，不构成本轮正式安装器的通过声明。

## 浏览与排序

- 从父相册进入子相册再返回时，在内存预算内恢复原卡片按钮、图片元素、已加载状态和滚动位置，再后台校验数据。最多保留两个非活动视图，共享最多 180 张真实卡片，每个视图最多七页数据与高度摘要，不保留全库 DOM。
- 恢复后按项目身份和数据代次（epoch）校验刷新，过期回包不能覆盖当前视图。当前尺寸、密度或 DPR 改变时重新布局；更换缩略图档位时才更新对应图片地址。仅改变请求队列优先级不会重新载入同一封面。超出预算、清理缓存或资料确实改变时允许冷加载；原有液态／磨砂玻璃与外观选择保留。
- 导入根目录所列一级相册默认名称升序；进入一级相册及其后代目录默认日期倒序。判定依据是导入根身份，不按磁盘路径有几层猜测。用户明确选择的排序和方向按页面保存，优先于默认值。
- 日期缓存未准备完成时，先按名称升序呈现，完成后对需要日期排序的活动页面按项目身份重排，保留未变化卡片。文件夹仍优先；文件夹日期用创建时间回退修改时间，照片优先已有 EXIF 拍摄日期，其他媒体使用有效文件系统时间。

## 日期准备的真实进度

日期回填按有界批次提交，事务外让出事件循环，并保存续作游标。中断或失败不把未完成数据标为就绪；已有触发器继续处理插入和日期变更。右下角区分读取状态、已提交回填数量、两个索引的建立阶段和失败状态。

日期回填使用 `migrateAsync`，默认每批 512 条、上限 4096 条。SQLite 的 `COUNT` 和单个 `CREATE INDEX` 调用内部仍为同步原生操作；程序在批次及两次建立之间让出执行，不宣称整个启动完全无阻塞。回填比例不是所有日期准备工作的整体比例，索引阶段使用不定进度。

## 更新下载

本体更新使用明确的运行时 ZIP 和清单，不能用普通 Standard 安装器冒充保留 Full 资源的更新。只有发布身份、平台、资源版型、数据版本、读取兼容性、文件大小和 SHA-256 都满足校验时，才启用保留原索引的本体更新。旧发布缺少本体清单时，仍提供完整安装器下载；下载和安装均需用户操作。

自动安装另外要求当前程序具备可信的逐文件所有权清单，完整安装器也必须生成与目标版本一致的新清单。缺少清单、存在未知文件或校验不符时停止自动安装，并给出 GitHub 手动更新入口；完整安装失败时恢复原载荷。开发时既有的公开 1.2.1 安装器没有这份新清单，该旧产物不能视为通过新版自动安装验收。后续正式处理为替换 v1.2.1 同版本附件，安装与验证以当前 [1.2.1 说明](RELEASE_NOTES_1.2.1.md) 为准。

正式程序按当前实际随包索引识别 Standard / Lite / Full，保留原库后不受共用本体包中的版型提示影响。只有确认索引目录不存在时才判为 Standard；清单损坏、未知协议或路径不可信时显示未知版型，要求明确选择并停止默认下载。

运行时载荷支持随包的中文等合法 Windows 文件名，继续拒绝越界、设备名和非法路径；安装和回滚均按清单逐文件校验，失败保留恢复证据和原程序。个人资料、图库原路径与 ID、Token、收藏、人工关联及本机五份私有字体继续保护。专有字体不放入公开本体载荷；已有本机字体通过受控外置层保留。下载弹窗沿用现有外观，显示实际字节进度、错误原因和可点击的 GitHub 发布链接。

## Everything 评估

已检查本机 Everything 安装及官方 SDK / IPC 文档。官方 IPC 查询依赖运行中的 Everything，日期字段和快速排序配置可选，不能替代 EXIF 日期语义或文件系统身份校验。本轮使用现有 SQLite 分页与索引，不增加 FFI、SDK 包或常驻搜索依赖。

## 验证与保护边界

本机开发阶段的验证数量和构建摘要以当时交付报告为准，仅属于历史结果；2026-11-06 正式同版本替换验收尚待完成，以待发布的 `VALIDATION_REPORT.md` 为准，不沿用历史通过数字作新声明。测试使用独立资料库与生成素材；`D:\ACG图片` 和 `D:\游戏图片` 仅允许读取，不允许改名、移动、删除或写入。个人资料库、两个启动入口、原 Full / Lite 资源与旧正式产物是保护对象，正式替换需按当前交付流程保留回滚证据。真实 Windows NSIS 覆盖安装、UAC、注册表与系统重启全链路未在用户环境端到端实测，模拟测试不能代替。
