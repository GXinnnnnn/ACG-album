# 本地外观控制与可读性修订

2026-10-30，在 1.1.1 本地试用版本上完成外观控制。现纳入同号全套发布替换：更新源码、GitHub `v1.1.1` 标签与描述、三版公开安装器和说明／校验附件，并同步固定 `C:\ACG\当前版本` 完整 Full 程序及 `C:\ACG\安装包`。同号用户须手动覆盖安装，实际发布结果以本轮回读记录为准。

## 外观设置

- 全局字体阴影开关默认关闭。开启后使用柔和阴影，不增加发光、文字描边，也不改变图标样式。
- 液态玻璃透明度：0–90%，默认 18%；磨砂玻璃透明度：0–90%，默认 8%。数值越小越不透明。两个控制分别作用于悬浮液态层和窗口磨砂底色，改变材质而不降低文字、图标和控件本身的不透明度。关闭液态效果或 GPU 不可用时，基础材质仍遵循可用的透明度设置。
- 全局卡片圆角：0–36px，默认 16px。0px 为方角；相册、媒体与分类封面裁切保持一致，圆形头像和功能按钮保持原形。
- 卡片尺寸：120–360px，默认 222px，保留 158／186／222px 三档快捷按钮。网格按可用宽度从左上方排布，窄窗口下限制卡片实际宽度以避免横向溢出。
- 每个调节滑杆右侧均有恢复默认按钮，悬停显示“恢复默认值”；支持点击轨道和键盘操作。查看设置中的尺寸控制共用同一设置。原有封面缩放／位置、图片调色色彩滑杆也增加逐项恢复按钮；播放定位条仍用于播放位置。

## 视觉与性能

- 中置窗口和滚动内容采用更细、偏粉色的滑块，透明轨道；保持内部内容滚动和玻璃外壳四边完整覆盖。
- 浅色主题悬浮文字加深，图标颜色略加深；深色主题相应提高亮度。保留强调色、危险操作、媒体白字的语义和极性。搜索框、Bangumi 网址等空字段占位提示继续使用独立淡灰色。
- 保留所有现有图标的路径、线条、大小和形状，仅调整颜色。
- 拖动按动画帧合并实时预览，保存防抖并按顺序写入。重复值不触发多余材质更新；卡片尺寸变化复用已加载数据，保存后保留选择，重启恢复。检索、导入稳定性及无中央遮罩的均匀玻璃材质保持。
