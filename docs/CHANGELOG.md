# 更新记录与版本规则

## 1.1.1 全套替换修订 · 2026-10-30

- 外观增加字体阴影开关、独立液态／磨砂透明度、卡片圆角和连续尺寸调节。滑杆右侧支持恢复默认、键盘操作与实时预览；合并保存和重绘，重启保留。
- 窗口默认更不透明，滚动条更细偏粉；悬浮文字与图标颜色加深，保留空字段占位提示和所有现有图标样式。
- 卡片圆角支持 0px 方角，尺寸覆盖 120–360px 与原三档，自适应左上对齐网格。原有封面位置、缩放及图片调色滑杆增加逐项恢复。
- 弹窗采用整面均匀磨砂，取消中央遮罩与过渡带，修复属性、封面位置、详细信息及右键浮层的右侧多余区域，内容内部滚动、焦点环完整。
- 自动／手动检索统一有限分页及缓存，首项同名被详情核验推翻后继续后页召回；保留置信门槛与歧义保护。导入与设置快照按变化刷新，减少目录树重建和玻璃场景上传。
- 更新源码、发布描述、本地完整程序及三版正式安装器，沿用现有 v1.1.1 标签和同一发布记录，替换全部八项附件。README 五张用户截图保留；构建配置去除重复合并的资源映射，避免同名演示文件复制冲突。
- 同号 1.1.1 用户需手动下载并覆盖安装，本次不触发严格更高版本的更新提示。

说明见 [本地外观控制](LOCAL_APPEARANCE_CONTROLS.md) 和 [本地弹窗与导入管线修订](LOCAL_POPUP_PIPELINE_REFINEMENT.md)。

## 1.1.0 · 2026-10-28

本次大版本汇集 1.0.1 正式发布之后的本地试用改动，保留应用身份、个人资料、收藏、封面、关联和缓存配置。

- WebGL2 液态玻璃、整窗滚动、侧栏与顶部导航统一调整；图片经过悬浮组件下方时文字仅增加淡阴影，去除发光和描边。查看器保留淡磨砂边框和清晰的中央媒体。
- 默认优先使用方正兰亭圆*GBK*中，已有个人字体选择继续优先；悬浮组件字号、切换栏轮廓与轻微内嵌阴影、主内容两侧留白调整。公开版使用本机已有字形或系统回退，不附带专有字体文件。
- 首页英文眉题、标题和说明支持单击原位编辑、粉色光标及底部编辑线，回车或失焦保存、Esc 取消、重启保留。三种首页筛选均可编辑；单行输入按实际显示宽度限制到可用内容宽度一半，处理中文输入法和多行粘贴。
- 图片增加按内容识别、兼容预览、离线 HEIC / HEIF 解码及缓存恢复。原图保持不变；保留具体解码失败原因。视频内播失败或约十秒未加载时回退系统默认播放器。
- 我的相册主卡图片与文字整体缩放和倾斜，展开预览保持稳定；调整搜索框、弹窗、右键菜单与分层字体选择。
- 完整原名、双语标题、数字与括号卷号的作品匹配继续优化；自然排序、数量显示、移除分类和扫描心跳修复。导入过程中提前显示本地封面，加快缩略图流水线并复用有效缓存。
- Standard / Lite / Full 重新构建并保留相同应用身份。索引快照仍为 2026-10-13.210353Z；Full 和 Lite 的名称覆盖相同，Full 额外保留完整资料。

安装三版之一即可。退出程序后覆盖安装可继续使用原数据。曾使用重定版前历史 1.1.0 / 1.1.1 / 1.2.0 的用户应手动下载本次安装包：软件只提示严格更高的版本，同号或较低编号不会触发更新提示。验收结果与精确文件校验值随 Release 附件提供。

## 后续版本

- 小范围修复或调整：末位加一，例如 1.1.0 → 1.1.1。
- 大改动或一轮完整功能更新：中间位加一、末位归零，例如 1.1.1 → 1.2.0。
- 每次同步更新源码版本、说明、GitHub 标签与附件、本地正式安装包和固定运行目录，替换确认已被新成品覆盖的旧载荷，保留用户数据与验收记录。
