# 本地弹窗磨砂边界修订

2026-10-29，在 1.1.1 上完成弹窗边界调整，纳入同号正式替换发布。

- 弹窗中央磨砂圆角矩形以原文字包围范围距离外框最近的一边为标准，统一四边内缩距离；短内容页面底部也延伸到相同边距，不再随着最后一行文字提前结束。根据本地试用反馈再将中央区域每边收小 2px，设置页留白由 16px 调整到 18px。
- 设置、本地搜索和目录绑定等由内部面板承担滚动的弹窗，外壳取消重复滚动条槽，避免右侧玻璃画布少铺一条所形成的半透明长条。内部滚动、滚动条主题和真正需要外壳滚动的弹窗保持正常。
- 本轮实际 Electron 验收包含五个设置页、关于、检查更新的明暗主题和顶部/底部状态。设置页四边磨砂内缩均为 18px；680px 外壳的玻璃画布宽 678px，左右各距外框 1px，均为正常边框。

本轮交付范围为源码和 `C:\ACG\当前版本` 的完整本机 Full 程序，以及 Standard/Lite/Full 三版公开安装器。按用户要求原位替换 GitHub 1.1.1 的源码、标签和全部附件；版本号仍为 1.1.1，正式发布新版本时再遵循项目版本递增规则。保留现有字体、查看器、离线索引、个人资料与两个固定启动入口。同号替换不会触发严格更高版本的自动更新提示，已安装旧 1.1.1 的用户可从发布页手动下载安装。
